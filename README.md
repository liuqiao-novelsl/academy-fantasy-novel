# 学院流西幻小说（试读稿）

一个没有巫师天赋的骑士，跟随拥有观测天赋的艾琳进入维兰学院。他们从石桥上的一枚铜环出发，追查畸变兽的来源，也开始寻找骑士道路之外的可能。

目前收录前五章正文与第一卷暂定大纲。正文建议按顺序阅读；大纲包含后续情节、人物动机与结局剧透，可在读完试读章节后再打开。
